# Playbook

How these remakes are built, in reading order:

1. [approach.md](approach.md): the four ideas everything rests on (drawn by code, label grids, scripts that run,
   chapters).
2. [chapter-loop.md](chapter-loop.md): the order of work for each chapter and its exit criteria.
3. [tools.md](tools.md): the headless tools and when to use each one.
4. [lessons.md](lessons.md): the mistakes that cost the most time. Read it before a new game, and skim it whenever
   something looks stuck.
5. [new-game.md](new-game.md): starting a new game from the latest one.
6. [games/](games/): notes about one source game (`emerald.md` for Gen 3 decomps, `red.md` for Gen 1).
